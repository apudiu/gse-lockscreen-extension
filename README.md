### Gnome Lockscreen Extension (GNOME V42 and above)

### Install
```
git clone https://github.com/pratap-panabaka/gse-lockscreen-extension
cd gse-lockscreen-extension
./install.sh
```

### Uninstall
```
./uninstall.sh
```
